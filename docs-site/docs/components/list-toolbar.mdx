# ListToolbar

Search, a filter flyout, the active-filter chip strip and a result count — the one toolbar every list screen uses.

The flyout is where filters are **set**; the chip strip is where ones already applied are **removed**. It is deliberately not a second place to set them.

## Import

```tsx
import { ListToolbar } from '@scaffald/ui';
```

## Basic Usage

<LivePreview code={`<ThemeProvider initialTheme="light">
  <Stack style={{padding: 16}}>
    <ListToolbar searchPlaceholder="Search applicants" resultCount={248} resultNoun="applicant" />
  </Stack>
</ThemeProvider>`} />

## The result count

One template everywhere — `{n} {noun}`. The prototype's audit found this slot phrased four different ways across the app.

<LivePreview code={`<ThemeProvider initialTheme="light">
  <Stack gap={12} style={{padding: 16}}>
    <ListToolbar resultCount={0} resultNoun="applicant" />
    <ListToolbar resultCount={1} resultNoun="applicant" />
    <ListToolbar resultCount={12} resultNoun="company" resultNounPlural="companies" />
  </Stack>
</ThemeProvider>`} />
