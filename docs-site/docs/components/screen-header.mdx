# ScreenHeader

The one header every screen uses: kicker → title (+ optional collapse caret) → tip (+ optional pager), with room for actions on the title row and a full-width slot beneath.

Every part except `title` is optional. A screen that only needs a title renders one and nothing else moves.

## Import

```tsx
import { ScreenHeader } from '@scaffald/ui';
```

## Basic Usage

<LivePreview code={`<ThemeProvider initialTheme="light">
  <Stack style={{padding: 16}}>
    <ScreenHeader title="Applications" />
  </Stack>
</ThemeProvider>`} />

## With kicker and tip

The kicker is the screen's context, not a second title.

<LivePreview code={`<ThemeProvider initialTheme="light">
  <Stack style={{padding: 16}}>
    <ScreenHeader
      kicker="Employer view — applicant workflow"
      title="Applications"
      tip="Move candidates between stages with the arrows — the worker sees each move as honest progress, not silence."
    />
  </Stack>
</ThemeProvider>`} />
